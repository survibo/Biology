
pdf 페이지 기준으로 N페이지를 범위로 잡고, 아래 형식에 맞춰 관련 시험 문제 약 70개를 JS로 만들어줘.

문제 제작시에 출처를 검토용으로 주석으로 명시해놔(오류 최소화 목적)

type은 choice로 고정해서 문제 만들어.

**[정답 분포 규칙 - 반드시 준수]**

문제를 다 만든 후, 반드시 아래 표를 먼저 출력할 것:

| 정답 index | 문제 수 | 해당 id 목록 |
| ---------- | ------- | ------------ |
| 0          | ?       | ...          |
| 1          | ?       | ...          |
| 2          | ?       | ...          |
| 3          | ?       | ...          |
| 4          | ?       | ...          |

표에서 각 행의 문제 수가 약 20%가 아닌 경우, 코드를 출력하기 전에 해당 문제들을 수정하여 20%로 맞출 것. 표가 20%로 균등하게 확인된 후에만 코드 블럭을 출력할 것.

규칙:

1. type은 반드시 "choice"로 고정
   * choice: 오지선다. 객관식 문제로 정답은 오직 하나 존재해야 함.

     prompt는 배열로 작성: ["문제문", "선택지1", "선택지2", "선택지3", "선택지4", "선택지5"]

     answers는 정답 선택지의 0부터 시작하는 index 하나만 작성: 예) 세 번째 선택지가 정답이면 answers: [2]
2. 답이 문제 안에 노출되지 않도록 할 것
3. 코드 블럭으로 출력할 것

지엽적인 문제 기준 (이런 문제는 만들지 말 것):

* 비유·묘사 표현을 암기하는 문제
* 다른 문제와 질문 또는 내용이 중복되는 문제
* 상식 수준으로 답할 수 있는 문제

문제 생성 후 코드 출력 전, 반드시 아래 항목을 검토하고 수정할 것:

* 답이 문제에 노출된 경우
* type 또는 answers 배열 개수가 잘못 지정된 경우 (answers는 반드시 index 숫자 하나만)
* answers 누락 또는 오류
* 지엽적이거나 질문이 중복되는 문제
* 정답 분포 표가 20%로 균등한지 최종 확인
